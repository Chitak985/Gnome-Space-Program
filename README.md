# Gnome Space Program

A C# spaceflight simulation game built in Godot.

### Contribution info is in [CONTRIBUTING.md](https://github.com/Sushutt/Gnome-Space-Program/tree/main?tab=contributing-ov-file#notes-for-contributors)

## Godot Version
Gnome Space Program currently uses Godot 4.6.1 Mono with Large World Coordinates. See [BuildingGodotEditor.md](https://github.com/Sushutt/Gnome-Space-Program/blob/main/BuildingGodotEditor.md) on how to build one of your own.
